# NSMB PC Port (Fan Game)

A fan-made recreation of New Super Mario Bros. for PC, with extra fun game modes.

This project is open source. Anyone can fork it, change it and build on it.

## Status

Just started. Nothing playable yet.

## Important

This is an unofficial fan project. It is not affiliated with or endorsed by Nintendo.
Super Mario and New Super Mario Bros. belong to Nintendo.

This repository only contains original code. It does not contain any game files, graphics, music or sounds from Nintendo. Please do not upload any of those here.
